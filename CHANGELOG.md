# Changelog

All notable changes to the RunQL Microsoft SQL Connector will be documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] — First Release

### Added
- Initial release.
- Microsoft SQL connection provider.
- `MSSQLAdapter` with query execution, non-query execution, and schema introspection (tables, columns, procedures, functions, parameters).

## [1.0.1]

### Changed
- change extension icon.
- Publish to Open VSX marketplace

## [1.2.0]

### Changes

#### More Table Actions in RunQL Explorer

Right-click any table in RunQL Explorer to:

- Copy the table name
- Edit the table
- View table DDL
- Generate SELECT, INSERT, UPDATE, and DELETE templates
- Dump table structure
- Generate mock data
- Copy, drop, or truncate a table

## [1.3.0]

### Changes

Add support for leveraging the core SSH Tunnel capability in the RunQL extension.
